# SAM Muttakin — Portfolio

A responsive personal portfolio website for **SAM Muttakin**, a Computer Science graduate and game developer interested in gameplay systems, vehicle simulation, computer graphics, and AI.

## Live site

After enabling GitHub Pages, the site will be available at:

`https://muttakinsiam.github.io/muttakinsiam/`

## Features

- Responsive layout for desktop, tablet, and mobile.
- Accessible navigation with a mobile menu.
- About, skills, selected projects, experience, and contact sections.
- Lightweight static site using HTML, CSS, and vanilla JavaScript.
- No build system or package installation required.

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/muttakinsiam/muttakinsiam.git
   ```
2. Open `index.html` in a browser, or serve the folder with any local static server.

## Enable GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/ (root)` folder.
5. Click **Save**.
6. Wait for deployment, then open the published URL.

## Customize the portfolio

- Update the biography and experience in `index.html`.

- Add a professional profile image or project screenshots if desired.
- Add a CV link in the Contact section.
